# Campsite

에이전트가 만든 HTML 모션 작품(Vista)을 한 편씩 이어 보는 설치형 웹앱.

지금 이 저장소에는 코드가 없다. 구현 전에 합의한 스펙과 그 근거가 된 시안만 있다.

| 문서 | 내용 |
|---|---|
| [docs/spec.md](docs/spec.md) | 제품 스펙 v0. 화면 구조, 제스처, 링크, 반입 규격, 디자인 값 |
| [docs/acceptance.md](docs/acceptance.md) | 수용 기준. 사용자 흐름 40개 |
| [docs/open-questions.md](docs/open-questions.md) | 아직 정하지 않았거나 기기에서 확인해야 하는 것 |
| [reference/prototype/](reference/prototype/) | 스펙의 근거가 된 시안 소스. 실행용이 아니라 값과 동작을 읽는 용도 |

구현은 `docs/spec.md`를 기준으로 한다. 스펙과 시안이 다르면 스펙이 맞다. 스펙에 없는 것은 만들지 않고 `docs/open-questions.md`에 적는다.
