# Campsite 스펙 v0

2026-11-12. 시안으로 확인한 범위를 적는다. 구현하는 쪽은 이 문서를 처음부터 끝까지 읽고 시작한다.

## 1. 제품

Campsite는 에이전트가 만든 HTML 모션 작품을 한 편씩 이어 보는 설치형 웹앱이다. 사용자는 쓸어서 넘기고, 작품 안의 링크를 눌러 더 깊이 들어간다.

기존 영상 피드와 다른 점은 하나다. 작품이 HTML이라서 작품 안의 어떤 요소든 링크가 될 수 있고, 그 링크가 바깥 사이트, 다른 작품, 손으로 만지는 화면을 연다.

## 2. 용어

| 말 | 뜻 |
|---|---|
| Vista | 작품 한 편. 길이가 있는 HTML 문서 하나 |
| 캠프 | Vista의 묶음. 주제 하나, 만든 이 하나 |
| 편 | 캠프 안에서 Vista의 순서 |
| 무대 | Vista가 재생되는 카드 |
| 레일 | 캠프를 고르는 디스크 줄 |
| 커튼 | 위에서 내려오는 한 장. 내려오면 앱 전체가 한 장의 카드로 물러난다 |
| 시트 | 아래에서 올라오는 한 장. 링크가 연 것을 담는다 |

## 3. 범위

v0에 넣는다.

- 세로 피드: 무대, 편 표시, 제목과 동작, 레일
- 가로 전체 화면
- 커튼
- 발견
- 링크와 시트
- 밝은 화면과 어두운 화면
- 홈 화면 설치, 오프라인 셸

v0에 넣지 않는다.

- 작품을 만들거나 고쳐 주는 서버(예전의 Runner)
- 발행 전 품질 판정 모델
- 배경음과 효과음
- 햅틱
- 왼손용 배치 선택. 배치는 하나다
- 앱 안에서 HTML 파일을 직접 올리는 화면

## 4. 원칙

구현 중 판단이 필요하면 이 순서로 따른다.

1. 조작부는 작품을 덮지 않는다. 작품 밖에 자리를 가진다.
2. 모드를 만들지 않는다. 들어갔다가 나와야 하는 상태가 생기면 설계가 틀린 것이다.
3. 상태는 문구가 아니라 모양, 위치, 움직임으로 보인다. 안내 문장을 넣지 않는다.
4. 재생 중에는 시선 가장자리에서 움직이는 것이 없다.
5. 탄성은 손을 뗀 자리에만 쓴다(§11).
6. 로딩 화면을 만들지 않는다. 포스터를 먼저 깔고, 다음 한 편은 미리 불러 둔다.

광고 캠프는 캠프 이름 뒤에 ` · 광고`를 붙인다.

## 6. 제스처

| 손동작 | 어디서 | 결과 |
|---|---|---|
| 위아래로 밀기 | 무대 | 같은 캠프의 다음 편, 이전 편 |
| 좌우로 밀기 | 무대 | 다음 캠프, 이전 캠프 |
| 좌우로 쓸기 | 레일 | 캠프 이동. 무대가 같은 비율로 따라온다. 세게 튕기면 여러 칸을 지난다 |
| 톡 | 레일의 디스크 | 그 캠프로. 발견 화면에 있었다면 피드로 돌아온다 |
| 톡 | 무대, 링크가 아닌 곳 | 멈춤과 재생 |
| 누르기 | 무대 안의 링크 | §9 |
| 끌어내리기 | 상단 | 커튼 |

값.

- 방향은 처음 8px 움직인 쪽으로 정한다. 정해진 뒤에는 바뀌지 않는다.
- 넘김 확정: 이동 거리가 한 칸의 20%를 넘거나, 속도가 0.5px/ms를 넘고 24px 이상 움직였을 때.
- 처음과 끝에서는 손가락 이동의 30%만 따라오고 놓으면 돌아온다.
- 끄는 동안 무대는 손가락을 그대로 따라오며, 밀려나는 카드는 최대 8~10% 작아진다.
- 화면이 확대·축소돼 있어도 손가락 이동을 화면 좌표로 환산해 쓴다.

## 7. 재생

- 한 편이 끝나면 같은 캠프의 다음 편으로 넘어간다. 마지막 편이 끝나면 다음 캠프의 보던 편으로, 마지막 캠프에서는 첫 캠프로 간다.
- 커튼의 '다음 편 이어 보기'를 끄면 같은 편을 반복한다.
- 다음 중 하나면 재생 시간이 멈춘다: 멈춤, 끄는 중, 커튼이 내려옴, 발견 화면, 시트가 열림, 링크를 누르고 있음.

편 표시.

- 재생 중: 점만 보인다. 점의 수가 그 캠프의 편 수다. 지금 편은 16×4, 나머지는 4×4, 간격 6.
- 멈췄을 때: 지금 편의 점이 120×4 막대로 펴지고, 어디까지 봤는지 채워진다.
- 재생 중에 채워지는 막대를 보이지 않는다(원칙 4).

멈춤은 모양으로 보인다. 무대가 96%로 물러나고 가운데에 재생 표시(72)가 올라온다.

다음 캠프로 넘어가기 직전 3초 동안만, 레일에서 다음 캠프의 디스크 둘레에 강조색 링이 한 바퀴 돈다.

## 8. 레일

| 항목 | 값 |
|---|---|
| 디스크 | 44. 크기는 변하지 않는다 |
| 간격 | 12. 중심 사이 56 |
| 선택 링 | 디스크 밖으로 2 띄우고 굵기 2. 바깥지름 52 |
| 넘김 예고 링 | 선택 링과 같은 자리, 굵기 2, 강조색 |
| 안쪽 높이 | 52 |
| 전체 높이 | 68 |
| 추가 버튼 | 52. 레일 오른쪽 끝에 고정 |

- 디스크는 한 줄로 서고 줄 전체가 움직인다. 디스크마다 따로 위치를 계산하지 않는다. 겹치지 않게 하기 위해서다.
- 선택된 캠프가 레일 가운데에 온다.
- 가운데에서 멀어지는 디스크는 한 칸에 0.2씩 흐려지고 0.4에서 멈춘다.

## 9. 링크와 시트

Vista 안의 어떤 요소든 링크가 될 수 있다. 여는 일은 Campsite가 한다.

| 손동작 | 결과 |
|---|---|
| 링크를 누르고 있는 동안 | 손끝 위 72px에 목적지 표시가 뜬다. 재생은 멈추지 않는다 |
| 떼면 | 링크가 열린다 |
| 누른 채 8px 넘게 움직이면 | 링크는 취소되고 평소의 넘김이 된다 |
| 0.5초 누르고 있으면 | 열지 않고 담는다. 표시가 강조색 책갈피로 바뀌고 0.5초 뒤 사라진다 |

목적지는 세 가지다.

| 종류 | 여는 방식 |
|---|---|
| 바깥 사이트 | 시트 안의 브라우저, 또는 기기의 브라우저(미정, open-questions 참고) |
| 다른 Vista | 피드 안에서 그 편으로 이동 |
| 만지는 화면 | 시트가 올라오고, 그 안에서는 모든 손동작이 그 화면의 것이다 |

시트.

- 위에서 68 아래부터 화면 끝까지. 위쪽 모서리 32.
- 열리면 피드는 92%로 물러나고 모서리가 40으로 둥글어진다.
- 손잡이나 시트 위쪽의 빈 곳을 누르면 닫힌다.
- 열려 있는 동안 뒤의 작품은 멈춘다.

담은 링크는 계정 버튼에 강조색 점으로 표시되고, 커튼 안에 개수가 보인다.

Vista는 링크를 직접 열지 못한다. Campsite에 요청한다. 그래서 어느 작품의 어느 링크가 눌렸는지 Campsite가 센다.

## 10. 커튼, 발견, 추가

커튼.

- 높이 480. 내려오면 앱 전체가 492만큼 내려가고 94%로 줄며 모서리가 40으로 둥글어진다.
- 끄는 동안은 손가락을 따라오고, 22% 넘게 내리고 놓으면 끝까지 열린다.
- 물러난 앱을 누르거나 위로 밀면 닫힌다.
- 안에 있는 것: 계정, '다음 편 이어 보기' 스위치, '어두운 화면' 스위치, 담아 둔 링크 개수, 홈 화면에 추가.
- 설정 화면을 따로 만들지 않는다. 설정은 이 한 장이 전부다.

발견.

- 캠프가 2열 타일로 나온다. 타일 높이 144, 위쪽 그림 76.
- 타일을 누르면 레일에 올라가거나 내려간다. 상태는 타일 모서리 표시의 모양(+, ✓)으로만 보인다.
- 보던 캠프를 내리면 첫 캠프로 간다. 다른 캠프를 내리면 보던 캠프가 유지된다.
- 마지막 한 캠프는 내려가지 않는다.
- 발견 화면에서 레일의 디스크를 누르면 피드로 돌아와 그 캠프를 재생한다.

추가(+).

- 누르면 아래에서 한 장이 올라오고 선택지는 둘이다: Claude에서 만들기, ChatGPT에서 만들기.
- 고르면 그 앱이 열리고 Campsite 커넥터를 부르는 말이 미리 들어가 있다.
- 앱 안에서 HTML을 직접 올리는 길은 두지 않는다.

## 11. 디자인 값

색.

| 역할 | 어두운 화면 | 밝은 화면 |
|---|---|---|
| 앱 뒤 | `#000000` | `#d4d4d8` |
| 앱 바탕 | `#0f0f10` | `#f4f4f5` |
| 면 | `#19191b` | `#ffffff` |
| 올라온 면 | `#232325` | `#f4f4f5` |
| 글자 | `#ededed` | `#171717` |
| 글자 둘째 | `#a1a1a6` | `#525252` |
| 글자 셋째 | `#85858b` | `#737373` |
| 꺼진 트랙 | `#2e2e31` | `#d4d4d8` |
| 강조 | `#f0a47c` | `#c2562a` |

- 강조색은 하나다. 좋아요, 켜진 스위치, 넘김 예고 링, 담긴 링크에만 쓴다.
- 깊이는 유리나 색 그림자 없이 낸다. 어두운 화면은 면 윗변에 `inset 0 1px 0 rgba(255,255,255,0.12)`, 밝은 화면은 `0 1px 2px rgba(0,0,0,0.05), 0 0 0 1px rgba(23,23,23,0.06)`.
- 무대 안의 색은 작품의 것이고 화면 테마를 따르지 않는다.

글자.

- IBM Plex Sans KR, 굵기 400·500·600.
- 13/20(캠프 이름, 보조), 15/22(본문), 18/24(시트와 커튼의 제목).
- 숫자는 tabular-nums.

간격은 4의 배수. 누르는 면은 44 이상.

움직임.

| 쓰임 | 곡선 | 시간 |
|---|---|---|
| 누름, 색 바뀜 | `cubic-bezier(0.22,1,0.36,1)` | 140~160ms |
| 탄성: 무대 안착, 커튼, 시트, 레일, 좋아요·저장, 스위치 손잡이 | `cubic-bezier(0.3,1.4,0.5,1)` | 380~520ms |

- 탄성은 위 표의 자리에만 쓴다.
- 누르면 92%로 줄어든다.
- 움직이는 속성은 transform, opacity, 색뿐이다.

## 12. 가로 화면

시안의 현재 동작을 적는다. 이 절은 확정이 아니다(open-questions 1번).

- 재생 중에는 Vista가 화면 전체를 채우고 조작부가 없다.
- 한 번 누르면 멈추면서 무대가 줄어 가운데로 물러나고, 비워진 둘레에 조작부가 들어온다. 왼쪽에 세로 레일, 오른쪽에 계정과 동작, 아래에 제목과 탭.
- 넘기기는 세로와 같다.
- iPhone 가로에서는 양옆 59를 비운다.

## 13. Vista 반입 규격 v0

Campsite가 받는 Vista는 다음을 지킨다. 검사는 형식만 보고, 모델을 쓰지 않으며, 즉시 끝난다.

1. HTML 문서 하나다.
2. 길이를 알려 주거나 끝났다는 신호를 보낸다.
3. 포스터 한 장이 있다.
4. 세로와 가로 두 구도를 모두 가진다.
5. 격리된 프레임 안에서 오류 없이 뜬다.
6. 링크는 스스로 열지 않고 Campsite에 요청한다.
7. 빠른 쓸기를 자기 조작으로 쓰지 않는다. 쓸기는 Campsite의 넘김이다.

Vista는 남이 만든 코드다. 앱과 다른 출처의 격리된 프레임에서 실행한다. 이 부분은 줄이지 않는다.

Vista와 Campsite 사이의 메시지 이름과 모양은 아직 정하지 않았다(open-questions 6번).

## 14. 기존 저장소에서 가져올 것

비공개 저장소 campsite-duo의 웹 클라이언트에서 동작 계산만 옮긴다. 화면과 스타일은 옮기지 않는다.

- 커튼: 끌기 판정, 놓았을 때의 투영, 닫힘 기준
- 무대: 탭과 끌기의 구분, 포인터 하나만 받기
- 설치형 웹앱 셸

옮기는 코드에 참고 출처의 이름이 들어 있으면 안 된다.
