# 시안 소스

스펙을 정할 때 쓴 시안 세 장이다. 디자인 캔버스 전용 형식(`.dc.html`)이라 이 저장소에서는 실행되지 않는다. 값과 동작 로직을 읽는 용도로만 둔다.

| 파일 | 화면 | 스펙에서의 지위 |
|---|---|---|
| `Main.dc.html` | iPhone 세로 393×852 | 스펙 §5~§11의 근거 |
| `Pad.dc.html` | iPad 가로 1194×834 | §12. 확정 아님 |
| `Land.dc.html` | iPhone 가로 852×393 | §12. 확정 아님 |

알아 둘 것.

- 작품 견본은 캔버스 안에서 CSS로 그린 대역이다. 실제 Vista는 격리된 프레임에서 도는 HTML 문서다.
- 입체 상자는 CSS 입체 변환으로 만든 대역이다.
- 가로 두 장의 견본은 세로보다 오래된 것이고 링크 동작이 없다.
- 견본 가운데 저장소 이름과 상품은 지어낸 것이다. 경기 일정과 소식은 2026-11-11에 조회한 실제 자료이고 지금은 지난 내용이다.
